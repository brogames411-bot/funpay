
# FunPay Black Russia Monitor Bot

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Открой `main.py` и укажи:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN"
CHAT_ID = "YOUR_CHAT_ID"
URL = "ССЫЛКА_НА_РАЗДЕЛ"
```

## Запуск

```bash
python main.py
```

## Как получить BOT_TOKEN

1. Открой Telegram
2. Найди BotFather
3. Введи:
   /newbot
4. Скопируй токен

## Как получить CHAT_ID

Напиши боту:
@userinfobot
